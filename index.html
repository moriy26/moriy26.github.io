🛠️ How It Works

This plugin is designed to be invisible. It works in the background, doing three main things:

  • 🔍 Smart Probing: Every 60 seconds, it checks if a state template is missing or about to expire. If needed, it automatically fetches a fresh one from the Codex upstream.
  • 📥 Passive Collection: When you make normal requests, the plugin silently captures the turn state from response headers — no extra requests, no slowdown.
  • 🔄 Automatic Reuse: It injects the saved state into your next requests, making everything faster and smoother.

❓ Common Questions

Will this slow down my requests?

No. The plugin operates independently from your normal request flow. Probing happens in the background, and state collection is passive (just reading response headers).

Do I need to update anything?

The plugin handles everything automatically. States are renewed before they expire, and it adapts to changes in the upstream system.

Is my data secure?

Absolutely. Everything stays on your machine. The plugin only communicates with your configured CPA endpoint and the Codex upstream. No third-party servers involved.

What happens if a state expires?

Don't worry — the plugin detects this within 60 seconds and automatically fetches a new one. You might see a brief moment where the state is refreshed, but it's designed to minimize any impact on your work.
